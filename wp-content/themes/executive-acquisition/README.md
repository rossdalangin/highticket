# Executive Acquisition WordPress Theme

A premium, high-converting WordPress theme engineered specifically for high-ticket executive coaches.

## Installation
1. Upload the `executive-acquisition` folder to your `/wp-content/themes/` directory.
2. Activate the theme via the WordPress Dashboard.
3. Go to **Appearance > Customize** to configure your funnel settings.

## Funnel Configuration
The theme is designed to follow a 3-step psychological sequence:
1. **Front Page:** Set your home page to a static page using the `Front Page` template (automatic if `front-page.php` is used).
2. **Thank You Page:** Create a page and assign the `Thank You / Authority Bridge` template. Link your form's redirect URL to this page.
3. **Briefing Page:** Create a page and assign the `Executive Briefing` template. Link the CTA from the Thank You page to this page.

## Custom Shortcodes
Use these shortcodes to enhance your blog posts and case studies:

- `[roi_callout value="+140%" label="Leadership Efficiency"]`
- `[exec_quote author="John Doe, CEO"]Your quote content here...[/exec_quote]`
- `[cta_button text="Get Started" url="/#cta"]`

## Technical Optimization
- **Font Pre-connections:** Built-in for performance.
- **SEO Ready:** Customizer fields for Schema.org JSON-LD and OpenGraph images.
- **Mobile First:** Fully responsive using modern CSS Grid and Flexbox.
